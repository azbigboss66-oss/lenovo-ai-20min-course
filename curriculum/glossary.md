# 课程术语表

| 术语 | 课程中的准确解释 | 常见误解 |
|---|---|---|
| 人工智能（AI） | 从输入中推断并生成预测、内容、建议或决策等输出的机器系统 | 任何自动化都是 AI；AI 必然像人思考 |
| 生成式 AI | 生成文本、图像、音频、代码等新内容的 AI | 生成的新内容天然原创、真实或可用 |
| 大语言模型（LLM） | 在大量文本上训练、根据上下文预测 token 序列的模型 | 一个装着全部事实的数据库 |
| Token | 模型处理文本的基本片段，可能是字、词的一部分或符号 | 永远等于一个汉字或一个单词 |
| 上下文 | 当前请求中模型能够看到的指令、资料、示例和对话 | 模型自动知道公司最新情况 |
| Prompt | 本次交给模型的任务指令与上下文 | 只要有一个万能咒语就能保证正确 |
| 幻觉/虚构 | 模型生成了无依据、错误或相互矛盾的内容 | 模型在有意识地撒谎 |
| RAG | 请求时检索受控外部资料，并把相关内容提供给模型生成答案 | 接了向量库就自动真实可靠 |
| 工具调用 | 模型或程序调用搜索、计算、数据库或业务接口读取/改变外部状态 | 模型文字里说“已提交”就真的提交了 |
| 工作流 | 由代码或规则预先定义步骤和分支的执行路径 | 工作流一定比 Agent 落后 |
| Agent | 模型依据目标和环境反馈动态选择步骤或工具的系统 | 一个聊天窗口或拟人头像就是 Agent |
| Skill | 可版本化、可复用的任务过程包，包含触发、资源、步骤、停止和评测 | 一段更长的 Prompt；写了 `SKILL.md` 就已部署 |
| 评测（Evaluation） | 用代表性任务、基线和评分规则判断系统是否满足目标 | 让模型自评一句“很好” |
| 微调 | 用训练样例调整模型参数，使稳定行为更贴近目标 | 给模型安装最新知识库 |
| LoRA | 冻结大部分基础权重、训练低秩适配参数的一类高效微调方法 | 没有数据和回归成本的免费升级 |
| 预训练 | 用大规模数据与算力形成基础模型能力的训练阶段 | 企业遇到任何效果问题都应自己训练大模型 |
| 人在回路 | 在关键判断、风险和外部动作处由人审阅、批准或接管 | 让人给自动化过程点一次无意义的确认 |
| Trace | 对输入、版本、步骤、输出、调用和停止原因的可追踪记录 | 一条“运行成功”的日志就足够 |

课程内所有术语以本表为准；厂商产品名称只作为当时可复核的例子，不作为长期稳定定义。
