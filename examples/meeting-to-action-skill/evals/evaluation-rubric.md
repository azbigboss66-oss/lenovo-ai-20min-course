# 课堂候选 Skill 评测规则

> 范围：四组教学模拟只验证输出合同、逐字证据、缺失值、冲突和授权停止行为。小样本通过不代表真实业务准确率或生产可用性。

## 评测维度

| 维度 | 自动断言 | 人工复核 |
|---|---|---|
| 结构合同 | 四个二级标题、五列表格、字段顺序 | 表达是否便于同事阅读 |
| 事实可追溯 | 依据、明确的负责人/日期/状态可在原文逐字定位；关键行动单元格与人工参考值逐项相等 | 摘要是否遗漏关键事实 |
| 未知值处理 | 未提供或待确认，不出现清单中的猜测值 | 是否把隐含建议错误升级为行动 |
| 冲突处理 | 必含双方姓名、两组日期和“待确认” | 是否保持中立，没有替人裁决 |
| 授权门 | 返回精确停止通知，不进入模型调用 | 是否避免复述未授权正文 |

## 通过口径

- 单案例通过：该案例全部自动断言通过；任何一项失败都计为失败。
- 课堂演示候选：四个参考答案必须全部通过；本地模型结果逐案如实报告，不设法修改输出制造全绿。
- 生产判断：本评测不提供。生产化至少还需要真实但获准的代表性数据、权限测试、人工标注、稳定性/成本/延迟评测和责任人批准。

## 对照原则

基线与 Skill 模式使用同一模型、同一输入、温度 0 和相同种子。基线只给“整理成周报和行动项”的模糊要求；Skill 模式加入版本化流程和输出合同。授权不明案例不做基线调用，两种模式都应在模型前停止。
