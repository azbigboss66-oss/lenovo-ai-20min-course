# 七课课程内容自检清单

自检对象：面向工作经验丰富、AI 入门的联想同事的 7 节课程链。

## A. 受众、场景与学习链

- [x] 采用专业术语配白话解释，不使用儿童化表达，也不假设学员会写代码。
- [x] 7 节均为 15–30 分钟的独立短课，并形成判断—委托—求证—固化—编排—评测—落地的依赖关系。
- [x] 每课只突出一个主要方法，并要求一份可观察产出。
- [x] 主案例与练习覆盖跨部门会议、周报、产品资料、渠道反馈、工单/日志、评测和试点设计。
- [x] 所有具体项目、人员、客户、产品和流程均标记为教学模拟。
- [ ] 目标学员已完成一轮试讲，并验证术语难度与练习说明无需现场补充。

## B. 七课材料完整性

- [x] 每课均有 `outline.md`、`speaker-script.md`、`exercise.md` 和 `reference-answer.md`，共 28 份文件。
- [x] 每份讲稿有逐分钟段落、转场、提问、示范、练习指令、岗位迁移和快速收束句。
- [x] 每份练习包含明确任务、时间或步骤，并与参考答案直接配对。
- [x] 每份参考答案包含理由或评分标准，不只给一个字母或结论。
- [x] 7 份自动参考估时均在 15–30 分钟范围内。
- [ ] 讲师已按自己的语速逐课彩排并记录真实时长。

## C. 技术概念与递进关系

- [x] AI、生成式 AI、LLM、token、上下文和概率生成的边界清楚。
- [x] Prompt 五字段明确为教学归纳，不声称是唯一行业标准。
- [x] 参数知识、上下文、受控知识源与 RAG 不混淆；引用必须支持具体主张。
- [x] Prompt、Skill、工具、固定工作流和 Agent 分别对应不同问题。
- [x] Skill 包含触发、资源、步骤、停止和评测；`SKILL.md` 不被描述为已部署能力。
- [x] 评测同时考虑任务集、基线、评分、版本/Trace、质量、成本、时延和风险。
- [x] 微调、LoRA 与预训练解释了改变的对象、适用条件和代价，没有用作“高级感”装饰。

## D. Prompt、Skill 与评测干货

- [x] Prompt 提供完整五字段模板、模糊请求对照、失败定位和基于合同的迭代方法。
- [x] RAG 课同时拆分检索失败与生成/引用失败，避免只看最终答案正确率。
- [x] Skill 课引用真实存在的候选包、输出合同、四组输入/人工答案、脚本和 Trace。
- [x] 工具/Agent 课明确允许工具、最小权限、参数校验、确认点、超时、无进展停止与回滚。
- [x] 模型升级课提供按失败类型选择 Prompt、RAG、工具、Skill/工作流、Agent、微调或预训练的矩阵。
- [x] 综合课把技术选择收束为可交、可证、可责、可追和 30 天低风险试点。
- [x] `1/4 → 4/4` 始终写成四个虚构案例的保存快照，不写成生产准确率或统计显著结论。

## E. 联想工作边界与责任

- [x] 不包含真实客户、员工、SN、价格、合同、路线图或内部制度内容。
- [x] 公开联想负责任 AI 材料只用于责任背景，不冒充内部审批规则。
- [x] 输入授权、资料权限、系统写入、外部发送和不可逆动作分别处理。
- [x] 高影响动作必须显示对象、参数和内容，由有权人员确认。
- [x] 人在回路包含明确检查标准，不把“点一下确认”当成充分治理。
- [ ] 正式授课使用的工具、案例与品牌呈现已由相应内部责任人复核。

## F. HTML 教材与品牌

- [x] 1 个总览页和 7 个单课页可由 Markdown 内容源重新生成。
- [x] 普通模式保持学术汇报式精简，讲师模式显示详细讲稿。
- [x] 复制、答案展开、讲师模式、完成状态和课间导航在 Edge 中实际点验。
- [x] 1440×1000 和 390×844 截图无横向溢出，主内容各只有一个 H1。
- [x] Logo 来自 Lenovo Brand World 页面，保持 3:1 比例、官方颜色、至少 100px 宽度并记录 SHA-256。
- [x] 页面不用渐变、光晕、AI 机器人或装饰电路；正文不是图片。
- [ ] 已由联想品牌责任人确认该内部教材的最终 Logo 应用与版式。

## G. 研究对标

- [x] 对标 Google AI Essentials、Microsoft Generative AI for Beginners、OpenAI Academy、IBM SkillsBuild、Elements of AI、OECD、NIST 与联想公开材料。
- [x] 吸收零基础、短模块、工作案例、主动练习、角色分层、评测和治理闭环，而不是照搬平台课程目录。
- [x] 42 项来源记录链接、日期、课程用途和适用边界。
- [x] 技术结论优先使用国际组织、原始论文、开放规范和官方文档。
- [ ] 正式授课前已复核持续更新页面和当时有效的内部要求。

## 判定规则

未勾选项都是必须由讲师、目标学员或联想相应责任人完成的人类验收，不能由脚本伪造为通过。当前仓库等级是本地课堂候选，不是正式授课批准、品牌批准、学习效果证明或生产系统验收。
