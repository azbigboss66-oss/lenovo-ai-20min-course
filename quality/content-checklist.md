# 内容自检清单

## A. 受众与目标

- [x] 面向工作经验丰富、AI 入门的在职同事，不采用儿童化表达。
- [x] 以联想工作环境中的跨部门协作为主案例。
- [x] 课程结束时有可观察的学习成果，而非只罗列术语。
- [x] 所有具体项目、客户、人员和流程均明确标记为教学模拟。

## B. 20 分钟教学设计

- [x] 大纲为每个时间段分配分钟并标注听众产出。
- [x] 采用一个主案例贯穿，减少频繁切换造成的认知负荷。
- [x] 安排两次十秒级判断，让听众从被动听讲转向主动/建构参与。
- [x] 讲师指南包含超时删减顺序和 15 分钟备选版本。
- [ ] 讲师已按自己的语速完成一次 18–20 分钟现场彩排。

## C. 技术准确性

- [x] AI 定义以输入、推断、输出和影响为核心。
- [x] LLM 解释包含 token、上下文、概率生成、参数和自注意力。
- [x] 明确“流畅不等于事实正确”，并给出 NIST 风险来源。
- [x] Prompt、Few-shot、RAG、工具、Skill、工作流、Agent、微调和预训练边界清楚。
- [x] LoRA 被描述为参数高效微调方法，不被说成知识库或无风险捷径。
- [x] 厂商特定能力记录访问日期和时效边界。

## D. Prompt 实用性

- [x] 五字段法明确标注为课程记忆框架，而非唯一行业标准。
- [x] 完整 Prompt 包含目标、上下文、约束、输出、验收与停止条件。
- [x] 示例展示“未提供”和原文依据，不鼓励模型补全未知事实。
- [x] 解释角色设定的有限作用。
- [x] 提供可迁移到客户问题、产品资料和制度问答的例子。

## E. Skill 系统性

- [x] Skill 被定义为版本化过程包，而非超长 Prompt。
- [x] 示例包含 `SKILL.md`、参考资料和确定性脚本。
- [x] 包含触发、输入、步骤、资源、异常、停止、输出合同和人工验收。
- [x] 说明渐进式披露和有/无 Skill 的评测思路。
- [x] 不把文件存在、静态校验或脚本通过说成真实 Agent/生产能力。

## F. 企业责任与联想相关性

- [x] 使用联想公开负责任 AI 六支柱作为责任背景。
- [x] 转化为可交、可证、可责、可追四个工作问题。
- [x] 不包含真实客户、员工、设备序列号、价格、未公开计划或内部制度。
- [x] 明确公开教材不能替代联想当前内部政策与授权。
- [x] 工具调用和系统写入保留授权、人工确认和停止边界。

## G. PPT 可转制性

- [x] 10 页内容页各自使用完整结论标题。
- [x] 每页提供屏幕文字、视觉证据、时间和讲者提示。
- [x] 完整 Prompt 与详细定义留在讲稿，不复制成密集页面。
- [x] 第 11 页提供来源组织方式。
- [ ] 已在实际模板中检查字号、对比度、投影可读性和联想品牌规范。

## H. 研究与证据

- [x] 使用国际组织、政府框架、开放规范、原始论文、官方文档和学习科学来源。
- [x] 来源台账记录日期、用途和适用边界。
- [x] 关键技术结论在研究综述中有编号引用。
- [x] 明确哪些结论是研究事实、分析判断或课程建议。
- [ ] 正式授课前已重新检查厂商页面和联想内部要求是否发生变化。

## 判定规则

未勾选项均为正式授课前的人类验收事项，不应被自动检查改写为“通过”。仓库完成表示教材内容与结构已交付，不表示已经通过真实现场彩排、品牌审查、内部合规审批或生产部署。
