# 视觉忠实度台账

比较对象：

- 总览概念：`docs/design/course-home-concept.png`
- 单课概念：`docs/design/lesson-page-concept.png`
- 实现截图：`quality/screenshots/*.png`

概念图用于确定信息架构、视觉密度和色彩关系，不作为页面素材。概念中的 Logo 仅是 3:1 占位槽；实现替换为 Lenovo Brand World 来源的官方文件。

| 对比点 | 概念意图 | 最终实现 | 判定 |
|---|---|---|---|
| 1. 色彩 | 真白、近黑、灰与单一红色强调 | CSS 使用 `#FFFFFF/#111111/#5B616B/#F3F4F5/#E2231A`，无渐变和光晕 | 一致 |
| 2. 品牌位置 | 顶部右侧 3:1 Logo 槽 | 官方 3:1 红底白字 Logo 右对齐，桌面 120px、移动 105px | 一致且按规范升级 |
| 3. 首页首屏 | 左侧课程主张，右侧五步流程 | 保留双栏、两个主按钮和五步线性流程；宽屏标题不再孤字换行 | 一致 |
| 4. 课程地图 | 七课纵向路径，避免卡片墙 | 使用带编号、描述、时长和产出的七行列表 | 一致 |
| 5. 单课框架 | 左侧目录、中间课件、右侧时间线 | 248/820/238 三栏，当前课红色高亮，时间线固定在右侧 | 一致 |
| 6. 内容密度 | 学术汇报式结论与少量正文 | 普通模式只显示提纲、练习和折叠答案；讲稿默认隐藏 | 一致 |
| 7. 学员/讲师分层 | 同一页面切换讲师内容 | “讲师模式”展开逐分钟讲稿，按钮状态可见 | 一致 |
| 8. 交互 | 答案折叠、复制与课间导航 | 原生答案展开、复制提纲、完成状态、上一课/下一课均实现 | 一致 |
| 9. 移动端 | 单栏可读，课程导航仍可访问 | 390px 下 Logo 保持最小宽度，课程导航横向滚动，正文无横向溢出 | 一致 |
| 10. 图片策略 | 概念图含办公场景示意 | 最终站点不引入非必要照片，避免把生成图当作联想真实办公素材 | 有意简化 |
| 11. 首页中段 | 概念曾展示当前课详卡与办公图 | 最终改为完整七课列表、学习方法和四原则，减少首页与单课重复 | 有意偏差，信息更完整 |
| 12. 单课核心图 | 概念用箭头部件图 | 最终使用可复制文字链和表格，由 Markdown 统一生成 | 有意偏差，优先可维护与可访问性 |

## 视觉结论

最终实现保留概念中的核心关系：高留白、黑白灰基底、Lenovo 红色强调、清晰层级、线性课程路径和三栏教学框架。偏差均有明确理由：品牌规范优先、正文可访问性优先、内容源一致性优先。当前结果可作为内部课堂候选视觉，不等于品牌团队正式批准。
