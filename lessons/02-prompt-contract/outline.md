# 第 02 课｜Prompt：把要求写成工作合同

> 计划 25 分钟｜教学模拟｜主要产出：一份五字段 Prompt 合同

## 下课时你能做到

1. 解释 Prompt 为什么是任务接口，而不是神奇咒语。
2. 用五字段法补齐目标、上下文、约束、输出和验收/停止。
3. 把事实、建议和待确认事项分开。
4. 用一次小迭代修正输出，而不是反复“再专业一点”。

## 五字段法

1. **任务目标**：交付给谁，用来做什么。
2. **必要上下文**：允许使用哪些原始材料、术语和示例。
3. **约束条件**：不得猜测什么，必须保留什么，边界是什么。
4. **输出形式**：字段、顺序、篇幅、语言和格式。
5. **验收与停止**：怎样算完成，何时标“待确认”，何时停止并提问。

## 好 Prompt 的判断

不是看它有多长，而是看：别人能否执行、结果能否验收、缺信息时会不会停。
