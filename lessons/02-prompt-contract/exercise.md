# 第 02 课练习｜五字段 Prompt 合同

> 教学模拟｜建议 4 分钟

## 输入材料

模拟渠道反馈：

- F01：“入门材料信息完整，但第一页术语太密，新同事不容易找到开始步骤。”
- F02：“希望增加一个十分钟以内的实操例子，最好能直接复制模板。”
- F03：“我们团队两个人试用了现有材料，示例有帮助；不能代表其他团队。”

原请求：“帮我总结一下反馈，告诉我应该改什么。”

## 请填写

```text
任务目标：
必要上下文：
约束条件：
输出形式：
验收与停止：
```

## 互评清单

- 是否说明给谁看、用于什么决定？
- 是否只允许使用 F01–F03？
- 是否禁止把两个人的反馈外推到所有渠道？
- 是否区分原始发现和模型建议？
- 是否规定缺失、冲突或证据不足时的处理？
