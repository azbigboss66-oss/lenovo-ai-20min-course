# 第 04 课练习｜Skill 五部件设计卡

> 教学模拟｜建议 4 分钟

## 任务

把“每周跨部门会议记录整理为行动项草稿”设计为一个候选 Skill。

```text
触发：什么请求应该使用？什么请求不应使用？

资源：最少需要哪些输入、合同、参考资料或工具？

步骤：按什么顺序提取、核验、组织和输出？

停止：出现哪些缺失、冲突或未授权动作时必须停？

评测：用哪三个案例比较没有 Skill 和使用 Skill 的结果？
```

## 自检

- 是否写了至少一个“不触发”场景？
- 是否写了输入缺失和未授权动作两个停止条件？
- 是否定义输出合同，而不是只写“整理得专业”？
- 是否有正常、缺失/冲突、权限边界三类测试？
