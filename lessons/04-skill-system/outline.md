# 第 04 课｜Skill：把一次好结果变成工作能力

> 计划 27 分钟｜教学模拟｜主要产出：一个 Skill 候选包

## 下课时你能做到

1. 区分 Prompt、固定工作流和 Skill。
2. 用“触发—资源—步骤—停止—评测”检查 Skill 是否完整。
3. 解释为什么 `SKILL.md` 不等于已经部署的能力。
4. 为一个重复任务写出最小 Skill 设计卡。

## Skill 五部件

触发（何时使用） → 资源（需要什么） → 步骤（怎样做） → 停止（何时不做） → 评测（怎样证明）

## 成熟度阶梯

长 Prompt → 有说明的文件包 → 可运行候选 → 代表性评测通过 → 受控试点 → 获批生产能力

## 课堂证据边界

会议行动项 Skill 在四个虚构案例上保存了同一模型的基线 1/4 与 Skill 4/4 快照。它是课堂候选，不是生产准确率、上线批准或真实业务收益证明。
