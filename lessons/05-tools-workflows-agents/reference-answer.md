# 第 05 课参考答案｜架构随风险升级

> 教学模拟。真实权限以当时有效的内部控制为准。

| 场景 | 推荐起点 | 理由与确认点 |
|---|---|---|
| A | 模型生成 | 输入已提供且是公开内容；作者检查事实与语气即可，无需工具。 |
| B | 固定工作流 + Skill | 路径和字段稳定；在发布周报前由负责人检查未知项和数字。 |
| C | 受限 Agent + 只读工具 | 调查路径可能随错误码变化；限制到当前工单、只读、最多 6 步，根因由工程师确认。 |
| D | 先生成草稿，发送工具置于人工批准之后 | 对外发送代表组织表达；确认收件人、正文、附件和依据后才能调用发送。 |

## 评分标准

- 架构选择每题 1 分；理由每题 1 分；共 8 分。
- 为 C 写出工具范围、最大步骤和停止条件，加 1 分。
- 为 D 明确“预览后人工批准”，加 1 分。
- 如果 D 允许 Agent 无确认发送，最高 5 分。
