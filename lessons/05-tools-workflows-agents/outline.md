# 第 05 课｜工具、工作流与 Agent：自主性必须有边界

> 计划 25 分钟｜教学模拟｜主要产出：权限与人工审批图

## 下课时你能做到

1. 区分语言生成、工具调用、固定工作流和 Agent。
2. 按“只读—写入—对外—不可逆”判断动作风险。
3. 为高影响动作设置授权、预览、确认、日志和停止条件。
4. 判断什么时候固定工作流比 Agent 更合适。

## 自主性阶梯

生成草稿 → 调用只读工具 → 按固定工作流执行 → Agent 动态选择工具 → 高影响动作人工批准

## 最小控制面

允许工具清单、最小权限、参数校验、预算/超时、人工确认、Trace、失败回滚。
