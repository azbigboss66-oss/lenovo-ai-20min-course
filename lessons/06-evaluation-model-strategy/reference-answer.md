# 第 06 课参考答案｜让技术匹配失败原因

> 教学模拟。答案描述的是优先调查方向，不是未经评测的采购或上线建议。

| 失败 | 优先手段 | 关键证据 |
|---|---|---|
| A | Prompt/输出合同 + 确定性结构检查 | 冻结 20–50 个代表性输入，统计字段遗漏；确认不是资料缺失。 |
| B | RAG 的版本过滤、来源优先级和冲突规则 | 记录检索候选、版本、生效日期、引用片段和当前权威来源。 |
| C | 最小权限只读工单工具 | 验证身份、允许字段、参数范围、工具失败与超时处理；建议仍需人审。 |
| D | 评估监督微调或 LoRA | 独立训练/验证/测试集、稳定标签、数据授权、基线、回归集、成本与部署条件。 |

## D 的前置条件示例

1. 错误可在代表性任务中稳定复现。
2. Prompt、上下文和流程已达到可接受基线。
3. 训练数据有权使用，标签一致并覆盖边界。
4. 有完全隔离的测试集和安全/回归集。
5. 定义质量、成本、时延和风险门槛。
6. 保留旧版本，可在候选失败时回退。

## 评分标准

四题每题 2 分，D 的前置条件与回退 2 分，共 10 分。若 B 选择微调安装最新知识，或 C 认为模型应凭空知道工单状态，对应题不得分。
