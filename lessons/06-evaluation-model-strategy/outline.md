# 第 06 课｜评测与模型升级路线：先证据，后技术

> 计划 28 分钟｜教学模拟｜主要产出：技术选择矩阵与评测计划

## 下课时你能做到

1. 用任务集、基线、评分、版本和 Trace 组成最小评测。
2. 同时考虑质量、成本、时延和风险。
3. 根据失败类型选择 Prompt、RAG、工具、Skill、Agent、微调或预训练。
4. 解释微调、LoRA 和预训练分别处在哪一层。

## 评测闭环

定义成功 → 冻结代表性任务 → 跑基线 → 修改一层 → 同条件复测 → 分析失败 → 决定发布/继续/停止

## 技术升级顺序

Prompt → RAG/检索 → 工具 → Skill/工作流 → Agent → 微调/LoRA → 预训练

这不是强制流水线，而是优先排查低成本、可解释的问题；每次升级都必须由失败证据触发。
