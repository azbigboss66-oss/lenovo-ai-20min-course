# 第 01 课练习｜AI 任务分级

> 教学模拟｜建议 3 分钟

## 任务

为下列工作选择 A、B 或 C，并写一句理由。

- A：可以让当前获准 AI 工具辅助，输出由本人快速检查。
- B：可以辅助，但必须补充证据、权限或专业人员复核。
- C：当前不应输入该数据，或不应让 AI 自动完成该动作。

| 编号 | 工作任务 | 你的判断 | 理由 |
|---|---|---|---|
| 1 | 把一段已脱敏的模拟会议记录改成统一行动项格式 |  |  |
| 2 | 根据三份有版本号的公开产品说明，草拟差异表 |  |  |
| 3 | 在没有资料的情况下预测下季度某具体客户采购金额 |  |  |
| 4 | 把包含真实客户联系人和未公开价格的表格上传到未获准公共工具 |  |  |
| 5 | 根据获准知识库草拟售后答复，由服务专家发送前确认 |  |  |
| 6 | 让 Agent 自动向外部客户发送延期通知，不设审批 |  |  |

## 自检问题

你的理由是否至少提到以下一项：输入权限、事实来源、错误影响、人工确认、动作可撤销性？
