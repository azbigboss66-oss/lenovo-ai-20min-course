# 第 01 课参考答案｜重点是条件，不是字母

> 教学模拟。实际分类取决于当时获准工具、数据分级和业务流程。

| 编号 | 建议判断 | 原因 |
|---|---|---|
| 1 | A | 输入已脱敏，任务是格式化提取；仍需核对负责人和日期没有被补写。 |
| 2 | B | 可以生成草稿，但必须保留文档版本、逐项引用并由产品责任人确认。 |
| 3 | C | 没有证据的确定金额属于编造；可改为列出预测所需数据和假设。 |
| 4 | C | 数据未获准进入该工具，属于输入边界问题，不能靠 Prompt 修复。 |
| 5 | B | 有受控来源和专业复核，可用于草拟；最终答复仍由授权人员负责。 |
| 6 | C | 对外发送有代表性和业务影响，缺少人工确认与停止条件。 |

## 评分标准

- 6 分：每项判断 0.5 分，每项理由 0.5 分。
- 达标：至少 4 分，且第 4、6 题不能判断为 A。
- 真正掌握：能够说明“条件变化时分类也会变化”，而不是把任务永久贴上标签。

## 带回岗位

选择一项自己的重复任务，写出四行：输入、推断、输出、影响。不要写真实敏感内容，只写字段名称和风险条件。
