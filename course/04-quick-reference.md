# AI 工作速查：从一次请求到可验证能力

## Prompt 五字段

| 字段 | 你要写清什么 | 快速提问 |
|---|---|---|
| 目标 | 完成什么、给谁、支持什么决定 | “最终拿它做什么？” |
| 上下文 | 原始材料、背景、允许来源 | “模型凭什么回答？” |
| 约束 | 禁止项、必须项、篇幅和事实边界 | “最不能错的是什么？” |
| 输出 | 结构、字段、顺序和格式 | “下一位同事怎样接着用？” |
| 验收与停止 | 完成标准、缺失值、询问与停止条件 | “证据不足时怎么办？” |

> 五字段法是本课程的记忆框架，不是唯一行业标准。简单任务可以短写，高风险任务需要更明确的证据和停止条件。

## 技术选择

| 失败表现 | 先检查 | 常用手段 |
|---|---|---|
| 输出方向不对 | 目标、上下文、约束是否清楚 | Prompt |
| 缺少最新或内部事实 | 是否有权威、可访问、可引用资料 | RAG/检索 |
| 需要查询或执行真实动作 | 是否有获准系统和权限 | 工具 |
| 同类任务反复做 | 步骤、字段、异常能否标准化 | Skill/固定工作流 |
| 步骤无法预先确定 | 是否真需要动态规划与工具选择 | Agent |
| 稳定行为反复不达标 | 是否有代表性数据和独立评测 | 微调/LoRA |
| 需要形成广泛新能力 | 数据、模型、算力和训练工程是否成立 | 预训练 |

## Skill 八问

1. 什么时候触发？
2. 必须提供什么输入？
3. 执行步骤是什么？
4. 允许读取哪些资料？
5. 哪些机械检查交给脚本？
6. 遇到异常怎样处理？
7. 什么时候必须停止并找人？
8. 输出遵守什么合同，如何版本化和评测？

## 联想工作四问

- **可交**：数据可以交给当前工具吗？
- **可证**：事实有来源吗？
- **可责**：谁复核、谁决定？
- **可追**：资料、规则、版本和结果能追溯吗？

## 一句话方法

先定义结果，再提供证据；高频任务封装为 Skill；任何升级都由评测证明。
